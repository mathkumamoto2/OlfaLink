# OlfaLink 配線表（ESP32 DevKitを想定）

共通I2Cバスの利用を継続します。TGS2602/2603そのものがI2Cに接続されるのではなく、アナログ出力をADS1115で計測します。

| モジュール | センサー端子 | 接続先 | I2Cアドレス |
|---|---|---|---|
| ADS1115 | SDA / SCL | ESP32 GPIO32 / GPIO33 | 0x48 |
| SGP41 | SDA / SCL | ESP32 GPIO32 / GPIO33 | 0x59 |
| BME688 | SDA / SCL | ESP32 GPIO32 / GPIO33 | 0x76 / 0x77 |
| TGS2602出力回路 | Vout | ADS1115 A0 | アナログ |
| TGS2603出力回路 | Vout | ADS1115 A1 | アナログ |

全デバイスはGNDを共有してください。I2C信号線は**ESP32の3.3Vに適合するレベル**としてください。

**TGS回路の5Vについて**: これはTGS回路に供給する5Vであり、ESP32 GPIOやBME688/SGP41センサー素子の許容電圧を意味しません。電源ピンはモジュール基板の仕様で確認してください。ADS1115のアナログ入力電圧はADCの電源電圧・絶対最大定格の範囲内でなければなりません。5V駆動ADS1115でI2Cが5Vにプルアップされる場合、ESP32との間にI2Cレベルシフタを入れてください。

BME688がスキャンで見つからない場合は、SPI/I2C選択に関係するCSB、I2Cアドレスに関係するSDO、電源/GND、SDA/SCLを基板資料に従い確認してください。
